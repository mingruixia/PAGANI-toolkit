# Validating PAGANI on a GPU computer

The test suite in `tests/` compares every PAGANI tool with independent
reference implementations (numpy, scipy, networkx) on synthetic data:

| file | what is checked |
|---|---|
| `test_cpu_tools.py` | degree, clustering (binary, Onnela, Barrat), efficiency/Lp, modularity (Louvain, Newman), participation coefficient, small-world pairing, Maslov rewiring (degree sequence, independence, seeds), NIfTI conversion, error handling |
| `test_construct.py` | Pearson, Spearman and Kendall networks (r and sparsity thresholds, ties), group averaging (r and Fisher z), `.cormat`, NIfTI data types / scaling / extensions, constant voxels, argument checks |
| `test_graph_metrics.py` | betweenness, eigenvector centrality; on the GPU also `CUBFW_Lp` and the GPU Newman modularity |
| `test_gpu_scale.py` | ~4000-node inputs split into many GPU blocks, with the "data do not fit in GPU memory" streaming paths forced, for construction and path length; larger betweenness and eigenvector problems |
| `test_pipeline_e2e.py` | a script generated by the GUI runs end to end and produces every output (needs the GUI test helper from a build directory) |

Without a GPU (e.g. in continuous integration) the GPU tools are tested through
CPU builds of the same code (`build/test-bin`). On a computer with an NVIDIA
GPU the real executables of a package are tested.

## Running the validation on Windows

1. Install Python 3.9 or newer (python.org or Anaconda).
2. Unpack the PAGANI package, e.g. to `C:\PAGANI-2.1.0`.
3. In a command prompt in the source folder run

   ```bat
   tests\run_validation.bat C:\PAGANI-2.1.0
   ```

   The first run installs numpy, scipy, networkx and pytest. The whole suite
   takes a few minutes. The result is written to `tests\validation_report.txt`
   (including the GPU name and driver version) and `tests\validation_report.xml`.

Manually, from any shell:

```bat
set PAGANI_BIN=C:\PAGANI-2.1.0
set PAGANI_TEST_GPU=1
python -m pytest -v tests
```

## Running the validation on Linux

With Python 3.9 or newer, from the source folder:

```bash
tests/run_validation.sh /path/to/PAGANI-Toolkit-<version>-linux-x64
```

The report is written to the same files as on Windows.

## Comparing with results of PAGANI 2.0

Run the same analysis with 2.0 and 2.1 into two folders and compare them:

```bat
python tests\compare_results.py D:\old\unweighted D:\new\unweighted --csv compare.csv
```

For every network and metric file the report lists edge counts and edge-set
overlap (`.csr`), correlation and largest difference (`.nm`) or the values
(`.txt`). Differences are expected where 2.1 fixed a 2.0 problem — see the
"Results that change" table in `CHANGELOG.md`.
